I have analyzed the repository and identified a security vulnerability.

The vulnerability is located in the `Pimcore\Bundle\AdminBundle\DataObject\GridColumnConfig\Operator\PHPCode` class. This class implements a mechanism where it instantiates a PHP class specified in the configuration:

```php
81:     private function buildInstance(): OperatorInterface
82:     {
83:         $phpClass = $this->getPhpClass();
84: 
85:         if ($phpClass && class_exists($phpClass)) {
86:             $operatorInstance = new $phpClass($this->config, $this->context);
87: 
88:             return $operatorInstance;
89:         }
90: 
91:         throw new \Exception('PHPCode operator class does not exist: ' . $phpClass);
92:     }
```

The `phpClass` value is derived from the `$config` object, which is part of the `GridConfig`. The `DataObjectHelperController::gridSaveColumnConfigAction` allows an administrator (or a user with sufficient permissions) to save a `GridConfig` via a POST request, where the `gridconfig` parameter is a JSON string containing the configuration for grid columns.

If an attacker can influence the `GridConfig` (e.g., by having permissions to save their own grid configuration or by exploiting a vulnerability that allows modifying another user's configuration), they can specify an arbitrary class name in the `phpClass` attribute. If that class exists in the PHP environment and its constructor can be triggered to perform a malicious action (a "gadget"), this leads to an arbitrary object instantiation vulnerability. While it is not a direct `eval()`, it allows the instantiation of any existing class, which is a classic precursor to Remote Code Execution (RCE) in PHP when combined with suitable gadgets.
