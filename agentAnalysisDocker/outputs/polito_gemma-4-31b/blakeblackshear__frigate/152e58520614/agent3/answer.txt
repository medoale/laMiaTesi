During the security review of the repository, I examined the API endpoints, specifically looking for potential vulnerabilities such as SQL injection, broken access control, and insecure configuration handling.

In `frigate/api/app.py`, I observed the endpoint `/config/raw` (lines 216-233):
```python
@router.get("/config/raw", dependencies=[Depends(allow_any_authenticated())])
def config_raw():
    config_file = find_config_file()

    if not os.path.isfile(config_file):
        return JSONResponse(
            content=({"success": False, "message": "Could not find file"}),
            status_code=404,
        )

    with open(config_file, "r") as f:
        raw_config = f.read()
        f.close()

        return JSONResponse(
            content=raw_config, media_type="text/plain", status_code=200
        )
```
This endpoint allows any authenticated user (including those with the lowest privileges, such as "viewer") to read the raw configuration file of the application. Configuration files often contain sensitive information, such as API keys, database credentials, and passwords. Although the `/config` endpoint (lines 110-183) explicitly masks sensitive fields like `mqtt.password` and `proxy.auth_secret`, the `/config/raw` endpoint returns the entire file content without any redaction. This leads to a sensitive information disclosure vulnerability.
