The commit introduces a comprehensive fix for Server-Side Request Forgery (SSRF) vulnerabilities.

### Analysis:
1.  **Vulnerability Identification**: Before the commit, the application used `requests.get()` and `requests.post()` directly on URLs provided by users (e.g., image URLs in recipes, import URLs). While there was a basic `validate_import_url` function, it was insufficient.
2.  **Fixes implemented in `validate_import_url`**:
    *   **URL Normalization**: It now encodes paths and queries to prevent bypasses using unencoded characters.
    *   **Input Validation**: It rejects URLs containing control characters.
    *   **Advanced IP Resolution**: It now explicitly detects and handles various IP encodings (DWORD, Hex, Octal) that are often used to bypass simple SSRF filters.
    *   **Local Address Blocking**: It continues to block local addresses (e.g., `127.0.0.1`, `localhost`).
3.  **Introduction of `safe_request`**:
    *   The commit replaces `requests.request` with a `safe_request` wrapper across the codebase.
    *   **Redirect Handling**: The most critical improvement is that `safe_request` disables automatic redirects (`allow_redirects=False`) and manually handles them. It validates every single URL in the redirect chain using `validate_import_url` before following it. This prevents "SSRF via redirect" attacks, where an initial URL is safe, but redirects the server to an internal resource.
    *   **Circular Redirect Protection**: It implements a `visited_urls` set and a `max_redirects` limit to prevent Denial of Service (DoS) via circular redirects.
4.  **Widespread Application**: The `safe_request` wrapper is applied to numerous integration points (`CookBookApp`, `Cookmate`, `Paprika`, `Plantoeat`, `RecetteTek`, `RecipeSage`, `Dropbox`, `Nextcloud`, etc.), ensuring consistent security across the application.

The changes specifically target and mitigate SSRF by ensuring that neither the initial request nor any subsequent redirects can target internal network resources or use obfuscated IP formats to bypass filters.
