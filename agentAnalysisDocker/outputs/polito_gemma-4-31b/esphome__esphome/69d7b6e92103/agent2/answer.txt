The commit fixes a potential integer overflow vulnerability in the `ProtoDecodableMessage` class within the ESPHome API implementation. 

In the `count_repeated_field` and `decode` methods, the code was performing boundary checks using the pattern `if (ptr + field_length > end)` and `if (ptr + 4 > end)`. Since `ptr` and `end` are pointers and `field_length` is an unsigned integer, the addition `ptr + field_length` can overflow if `field_length` is sufficiently large. If an overflow occurs, the resulting pointer may be smaller than `end`, causing the boundary check to pass even when the data is actually out of bounds. This could lead to an out-of-bounds read when the code subsequently accesses the buffer.

The fix changes these checks to use subtraction (`end - ptr`), which is safe as `end` is guaranteed to be greater than or equal to `ptr`, and then compares the result with the required length.
