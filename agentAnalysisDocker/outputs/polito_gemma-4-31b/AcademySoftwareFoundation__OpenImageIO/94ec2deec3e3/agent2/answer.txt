The commit introduces several changes to the `DDSInput` class in `src/dds.imageio/ddsinput.cpp` that clearly address security vulnerabilities related to integer overflows and lack of input validation when parsing DDS files.

**Analysis:**
1.  **Integer Overflow Prevention:** The commit changes several variable types from `unsigned int` and `int` to `size_t` in functions like `internal_seek_subimage`, `internal_readimg`, and `read_native_scanline`. This is critical because image dimensions (width, height, depth) multiplied together can easily exceed the capacity of a 32-bit integer, leading to integer overflows. Such overflows often result in undersized buffer allocations, which subsequently lead to heap-based buffer overflows when the actual image data is read into the buffer. For example, in `read_native_scanline`, the calculation `z * m_spec.height * size + y * size` was performed using `size_t` but could have overflowed if `z` or `y` were large and the other variables were `int` or `unsigned int`.

2.  **Input Validation (Sanity Checks):** The commit adds a significant block of validation logic to `seek_subimage`. It now checks if the image resolutions are within reasonable limits based on the texture type:
    *   Cube maps are limited to $16384 \times 16384$.
    *   Volume textures are limited to $4096 \times 4096 \times 4096$.
    *   2D textures are limited to $32768 \times 32768$.
    
    Before this change, the code relied on values read directly from the DDS header without sufficient bounds checking, allowing a maliciously crafted DDS file to specify enormous dimensions, triggering the aforementioned integer overflows or causing massive memory allocations (Denial of Service).

**Conclusion:**
The commit fixes vulnerabilities related to integer overflows leading to buffer overflows and potential DoS through lack of input validation on image dimensions. These are classic examples of CWE-190 (Integer Overflow) and CWE-20 (Improper Input Validation), which in this context lead to CWE-122 (Heap-based Buffer Overflow).
