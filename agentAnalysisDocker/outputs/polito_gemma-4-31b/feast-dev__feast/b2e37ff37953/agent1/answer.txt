In PyYAML, `yaml.load()` with `yaml.Loader` (or without a specified loader in older versions) is capable of executing arbitrary Python code if the YAML input is untrusted, because it allows the instantiation of any Python object. `yaml.safe_load()` restricts the loading to a subset of YAML that does not allow arbitrary code execution, thereby preventing remote code execution (RCE) vulnerabilities.
