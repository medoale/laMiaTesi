## Critical Context
- This is a DAG workflow engine that executes user-defined steps via shell commands, SQL queries, SSH commands, Docker containers, etc.
- The eval system (`internal/cmn/eval/`) performs shell-like expansion including `${}` variable substitution and command substitution — this is a high-risk area for injection
- Command executor constructs shell command strings with user-controlled parameters — potential command injection
- SQL executor uses named parameter conversion (`:param` → `$N` or `?`) but the query itself comes from DAG step config — SQL injection if variables used unsafely
- No evidence of input sanitization for step command/script content in the command executor
