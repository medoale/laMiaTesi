#### Root Cause

In `/work/internal/persis/filedag/store.go`, the `locateDAG` function (line 603–625) takes a `nameOrPath` string directly from user input (URL path parameter `{fileName}`) and, when it contains a `filepath.Separator`, delegates to `findDAGFile()` (line 794) which calls `filepath.Abs(name)` **without validating the resolved path stays within the DAG base directory**.

This contrasts with the `generateFilePath()` helper (line 590–600) used by `Create()` — that function strips directory components via `filepath.Base()` and verifies the result is within `baseDir`. The `locateDAG` function has no such safety check.

#### Exploitation Paths

| Endpoint | Auth Required | Effect from path traversal |
|---|---|---|
| `GET /api/v1/dags/{fileName}` | Auth middleware (any authenticated user) | Calls `GetDetails` + `GetSpec` → reads and returns content of arbitrary `.yaml`/`.yml` file |
| `GET /api/v1/dags/{fileName}/spec` | Auth middleware (any authenticated user) | Calls `GetSpec` → reads and returns raw content of arbitrary `.yaml`/`.yml` file |
| `DELETE /api/v1/dags/{fileName}` | Auth + `PermissionWriteDAGs` | Calls `Delete` → deletes arbitrary `.yaml`/`.yml` file |
| `PUT /api/v1/dags/{fileName}/spec` | Auth + `PermissionWriteDAGs` | Calls `UpdateSpec` → overwrites content of arbitrary `.yaml`/`.yml` file |
| `POST /api/v1/dags/{fileName}/rename` | Auth + `PermissionWriteDAGs` | Calls `Rename` → moves arbitrary `.yaml`/`.yml` file into DAG directory |
| `POST /api/v1/webhooks/{fileName}` | **No auth required** (public prefix) | Calls `GetDetails` → confirms file existence of arbitrary `.yaml`/`.yml` file via error codes |

The `POST /api/v1/webhooks/{fileName}` endpoint is public in all auth modes (configured as a `PublicPathPrefix` in `api.go` lines 373 and 383), allowing an unauthenticated attacker to probe for the existence of arbitrary `.yaml`/`.yml` files on the server filesystem.

#### Impact

- **Information disclosure**: Arbitrary YAML file read by any authenticated user (e.g., Kubernetes configs, Docker Compose, CI/CD pipeline definitions)
- **File deletion / corruption**: Arbitrary YAML file deletion or overwrite by users with write-DAG permission
- **RCE chain**: Combined with the intended backtick command-substitution feature (`eval/substitute.go`), an attacker who can place a crafted `.yaml` file anywhere on the filesystem (e.g., `/tmp/` via another vector) can achieve remote code execution by loading it as a DAG via path traversal
