### Bug Found (Not Exploitable for Code Execution)

**CWE-754: Improper Check for Unusual or Exceptional Conditions**

- **File**: `/work/frigate/util/builtin.py`, line 116
- **Function**: `escape_special_characters(path: str) -> str`
- **Issue**: When `len(path) > 1000`, the function executes `return ValueError("Input too long to check")` instead of `raise ValueError(...)`. This returns a `ValueError` object rather than a string, violating the return type annotation.
- **Impact**: At the two call sites (`util/services.py:580` and `config/camera/camera.py:269`), the returned `ValueError` object is placed into a subprocess argument list. `subprocess.run()` converts it via `str()`, yielding the literal string `"Input too long to check"` as the ffmpeg input path. This causes a harmless ffmpeg failure (invalid path) and does not enable code execution because:
  1. The command is a list, so no shell interpretation occurs
  2. The object is at the end of the argument list (no argument injection possible)
  3. The string value is a fixed error message, not user-controlled
