### Security Impact
This is a **security vulnerability fix**. An untrusted client could request attribute values with an inflated `out->memref.size`, causing the TEE to copy unintended heap memory contents — including potentially other objects' key material, cryptographic secrets, or other sensitive data — back to the client. Since this runs in a Trusted Execution Environment (TEE/OP-TEE), the leaked data could include sensitive information from other secure-world processes.
