**After (fixed):**

{

    } else {

**Security impact:** A user who lacks the `predefined_properties` permission can call the `/admin/settings/properties` endpoint **without** providing a `data` parameter, bypassing the authorization check entirely. The method falls into the `else` branch, which queries and returns the full list of all predefined property configurations — including their names, data types, configuration values, and other sensitive metadata. This is an authorization bypass allowing unauthorized information disclosure.

The root cause is **Missing Authorization** — one code path (the listing path) was not protected by the permission check.
