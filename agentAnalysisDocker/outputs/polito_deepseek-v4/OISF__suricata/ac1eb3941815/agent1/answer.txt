## Analysis

This commit fixes a security vulnerability in Suricata's `detect-engine-alert.c`.

### The vulnerability (before the fix)

The `AlertQueueExpand` function doubles the alert queue capacity by computing:

```c
uint16_t new_cap = det_ctx->alert_queue_capacity * 2;
```

Both `det_ctx->alert_queue_capacity` and `new_cap` are of type `uint16_t`. When `alert_queue_capacity` exceeds `UINT16_MAX / 2` (i.e., ≥ 32768), the multiplication overflows:

- `32768 × 2 = 65536` → wraps to `0`
- `49152 × 2 = 98304` → wraps to `32768` (a *smaller* value than the current capacity)

The overflowed `new_cap` is then passed to `SCRealloc`, causing an undersized (or zero-size) heap allocation. Critically, the code then sets `det_ctx->alert_queue_capacity = new_cap` — a value that is now smaller than or equal to the original `alert_queue_size`. Subsequent writes into the queue (via `det_ctx->alert_queue[pos] = ...` in `AlertQueueAppend`) write past the end of the undersized heap buffer.

### The fix

1. An early-return guard `if (det_ctx->alert_queue_capacity == UINT16_MAX)` prevents any attempt to expand when already at the maximum representable capacity.
2. A check `if (det_ctx->alert_queue_capacity > (UINT16_MAX / 2))` caps the new capacity at `UINT16_MAX` instead of doubling into overflow.
3. The actual reallocation logic is extracted into `AlertQueueExpandDo`.

This prevents the integer overflow and the resulting heap buffer overflow.

### Classification

- **CWE-190 (Integer Overflow or Wraparound)** — The root cause: the `uint16_t` multiplication `det_ctx->alert_queue_capacity * 2` overflows, producing a small or zero value.
- **CWE-122 (Heap-based Buffer Overflow)** — The consequence: the overflow causes `SCRealloc` to allocate an undersized buffer, and subsequent writes to `det_ctx->alert_queue[pos]` write out-of-bounds on the heap. This is exploitable to corrupt adjacent heap metadata or data.

Both CWEs genuinely apply: the integer overflow is the immediate coding flaw, and the heap buffer overflow is the exploitable runtime consequence that the fix eliminates.
