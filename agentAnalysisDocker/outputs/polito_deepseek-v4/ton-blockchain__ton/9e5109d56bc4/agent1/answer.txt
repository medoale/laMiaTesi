If the TON VM's C7 register contains a non-tuple value at index 17 (`inmsgparams_idx`), the `as_tuple()` call would return a null `Ref<Tuple>`, and `tuple_index(t, idx)` would dereference that null reference — causing undefined behavior (likely a crash or memory corruption).
