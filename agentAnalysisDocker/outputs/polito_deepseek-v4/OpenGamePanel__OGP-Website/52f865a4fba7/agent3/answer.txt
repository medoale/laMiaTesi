## Root Causes

1. **No central input sanitizer** — `helpers.php` only filters `$_REQUEST['m']` and `$_REQUEST['p']` with regex. All other parameters are user-controlled.
2. **`stripinput()` is weak and only in `install.php`** — converts HTML entities only, does NOT prevent SQLi or command injection. Not even loaded by the main app.
3. **`clean_path()` is dangerously misnamed** — only normalizes slashes, does NOT block path traversal (`..`) or shell metacharacters.
4. **No prepared statements** — the entire database layer relies on `mysqli_real_escape_string` with string interpolation.
5. **Shell commands sent via XML-RPC without escaping** — `$remote->exec("command $user_input")` passes directly to the agent's shell.
