   ```php
   if (!$currentUser->canAssignUserGroups()) {

   ```

The inner loop's check was only triggered for groups not already in `$oldGroupIds`. The new early return ensures users without any group assignment capabilities cannot even enter the logic.

This is a classic **authorization bypass** (CWE-862: Missing Authorization). The endpoint `actionSavePermissions` lacked proper access control checks before processing the request, and `_saveUserGroups` could bypass group-assignment permission checks when no *new* groups were being assigned.
