## Analysis

**File changed:** `trunk/web/admin/problem_import_qduoj.php`

**What the commit does:** Adds `$file_name=str_replace('../', '', $file_name);` in two places, right after the filename is extracted from a zip archive entry via `zip_entry_name()`.

**What the original code does:** The script accepts a user-uploaded ZIP file (via `$_FILES["fps"]`) and extracts its contents. For each zip entry, it constructs a filesystem path by concatenating `$path` (which is `undefined`/`null`, so effectively just the entry name) with `zip_entry_name($dir_resource)`, and then writes files to disk using `file_put_contents()` and creates directories using `mkdir()` — all within a temporary directory like `/tmp/import_qduoj<timestamp>/`.

**The vulnerability (fixed by this commit):** An attacker can craft a ZIP archive whose entry names contain `../` sequences (e.g., `../../var/www/html/shell.php`). Since the entry name is used directly in file operations, the resulting path would escape the intended temporary directory and write files anywhere the web server process can write. This is the classic **Zip Slip** vulnerability. In the context of an online judge web application, this could allow an attacker to overwrite PHP scripts in the webroot, achieving remote code execution.

**CWE classification:** The most specific and direct match is **CWE-22: Path Traversal** (Improper Limitation of a Pathname to a Restricted Directory). The filename from the zip entry is not validated against the intended extraction directory before being used in file write operations. This also falls under **CWE-73: External Control of File Name or Path**, but CWE-22 is the more specific and appropriate classification for this directory traversal scenario.

**Note on fix completeness:** `str_replace()` replaces all occurrences of the literal string `../`, but it does a single pass and can be bypassed with sequences like `....//` (which becomes `../` after one pass). A more robust approach would involve realpath-based validation. Nevertheless, this commit clearly and intentionally fixes a security vulnerability.
