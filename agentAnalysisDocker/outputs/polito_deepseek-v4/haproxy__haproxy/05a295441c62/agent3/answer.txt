### Finding: DNS `resolv_read_name` Validation Bypass (Medium Severity)

**File:** `/work/src/resolvers.c`, **Line 630**

The check:
```c
if ((buffer + reader[1]) > reader)  // Only checks LOW byte!
```
should be:
```c
if ((buffer + (*reader & 0x3f)*256 + reader[1]) > reader)  // Check full 14-bit offset
```

**Impact:** A DNS compression pointer claiming to point backward can actually point **forward** (offset >= 256). However, the recursive call is still bounded by `bufend` and `dest_len` (DNS_MAX_NAME_SIZE=255), so the worst case is incorrect name decompression — not memory corruption. **Not a zero-day.**
