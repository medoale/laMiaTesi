## Vulnerability #1: LTI Consumer Parameter Injection (CWE-349)

**Location:** `/work/src/richie/plugins/lti_consumer/api.py` (line 36) → `/work/src/richie/plugins/lti_consumer/models.py` (line 141, 168, 178)

**Root Cause:** In `api.py` line 36, `user_infos = request.GET.dict()` captures **every** GET query string parameter without any whitelist filtering. These raw user-controlled parameters are then passed to `get_content_parameters()` (`models.py` line 132), which blindly spreads them via `**user_infos` into the `lti_parameters` dict (line 141). This dict is used to:
- Sign the OAuth1 LTI launch request (line 167-168): `client.sign(self.url, http_method="POST", body=lti_parameters, ...)`
- Return to the client as the LTI launch parameters (line 178): `oauth_dict.update(lti_parameters)`

**Impact:** An unauthenticated attacker can inject arbitrary LTI launch parameters. Particularly critical is `lis_outcome_service_url` — the URL where the LTI tool sends grade passback results. By injecting their own URL, an attacker can hijack grade passback, receiving student grades and outcome data. Other injectable parameters include `lis_result_sourcedid`, `tool_consumer_instance_guid`, and any custom LTI extensions.

The endpoint has **no authentication** (accessible to anonymous users) — only a `user_id` query parameter is required.

## Vulnerability #2: Stored XSS in LargeBanner Content (CWE-79)

**Location:** `/work/src/richie/plugins/large_banner/models.py` (line 53)

**Root Cause:** The `LargeBanner.content` field is a `TextField` rendered in three templates with `|safe`. The form uses `TextEditorWidget` (CKEditor) which accepts HTML. Unlike `SimpleText` (which calls `clean_html()` on save), `LargeBanner` performs **no HTML sanitization** before storing the content.

**Templates affected:**
- `/work/src/richie/plugins/large_banner/templates/richie/large_banner/large_banner.html` (line 19)
- `/work/src/richie/plugins/large_banner/templates/richie/large_banner/hero-intro.html` (line 8)
- `/work/src/richie/plugins/large_banner/templates/richie/large_banner/compacted.html` (line 6)

**Impact:** Any user with CMS plugin editing permissions can inject arbitrary JavaScript that executes in the browser of every visitor viewing a page containing the LargeBanner plugin.

## Vulnerability #3: Stored XSS in Licence Content & Description (CWE-79)

**Location:** `/work/src/richie/apps/courses/models/course.py` (lines 1257, 1277)

**Root Cause:** `LicenceTranslation.content` and `LicencePluginModel.description` are both rendered with `|safe` in `/work/src/richie/apps/courses/templates/courses/plugins/licence_plugin.html` (lines 22, 26). Both use `TextEditorWidget` (CKEditor) but neither calls `clean_html()` on save. The model comment says "should only be created by administrators" but this is a convention, not enforced in code.
